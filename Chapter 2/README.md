# Chapter 2: SDLC & BNPL Feature Planning

## 1. User Story (BNPL Integration)

> As a vintage fashion shopper, I want to use Buy Now, Pay Later (BNPL)
> options like Klarna/Clearpay during checkout, so that I can conveniently
> split my total purchase into flexible, interest-free installments.

---

## 2. Product Backlog Tasks & Estimation

| Task ID | Task | Estimate |
|---|---|---|
| TASK-01 | Add BNPL promotional banners and payment badges on product cards and checkout UI. | S - Small |
| TASK-02 | Develop dynamic currency converter and installment calculation logic in JS. | M - Medium |
| TASK-03 | Integrate third-party BNPL payment gateway API for checkout authorization. | L - Large |
| TASK-04 | Perform responsive design checks and cross-browser functionality testing. | S - Small |

---

## 3. Definition of Done (DoD)

- [x] **Responsive Design:** UI is completely responsive across Mobile, Tablet, and Desktop screens.
- [x] **Code Quality:** Source code is clean, formatted, and completely free of browser console errors.
- [x] **Git Workflow:** Feature branch `feature/payment-integration` created and pushed to GitHub.
- [x] **Pull Request:** Draft Pull Request (PR) successfully created on GitHub for peer review.
